# Alrededor de los Estados Unidos

Proyecto web interactivo desarrollado como parte del programa de TripleTen. Una página donde los usuarios pueden editar su perfil, ver fotos de lugares interesantes y dar "me gusta" a las imágenes.

## Características

- **Diseño responsivo**: Se adapta a dispositivos móviles y desktop
- **Interactividad**:
  - Edición de perfil mediante popup
  - Sistema de "me gusta" en tarjetas
  - Eliminación de tarjetas
- **Semántica HTML**: Estructura semántica y accesible
- **Metodología BEM**: Organización de clases CSS
- **JavaScript modular**: Código organizado y mantenible

## Tecnologías utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (ES6+)
- Metodología BEM
- Git para control de versiones
